# 用語集

| 用語 | 意味 | メモ |
| --- | --- | --- |
| CV | 交差検証スコア | ローカル検証の結果。 |
| LB | リーダーボードスコア | Kaggle の public/private スコア。 |
| OOF | Out-of-Fold prediction | 各行を、その行が属するfoldを学習に使っていないモデルで予測した値。 |
| SHA | Secure Hash Algorithmによるhash値 | 内容同一性の証拠。algorithmと圧縮前後のどちらをhashしたかを明示する。 |
| `planned` / `running` / `debug_completed` / `scaffold_completed` / `failed` | 実験の実行状態 | `metrics.json`のstatusに記録する。 |
| `usable` | 派生実験や提出に使える状態 | ユーザーが判断する実験status。 |
| `completed` | 必要な検証と記録を終えた状態 | ユーザーが判断する実験status。 |
| `deprecated` | 履歴として残すが再利用しない状態 | ユーザーが判断し、可能なら代替実験を併記する。 |
| `discarded` | 候補として使わない状態 | ユーザーが判断する実験status。 |
| `leak-risk` | 検証リークの注意表示 | 採用・不採用・完了の判断ではない。 |
| `検討メモ・設計不可` | 結果や実装方針に影響する未決事項が残るbacklog状態 | このリポジトリ内の管理用語。 |
| `設計可能・実験化未承認` | 実験境界が揃い未決事項がないが、実験化は承認されていないbacklog状態 | このリポジトリ内の管理用語。 |
| `faithful` / `staged-faithful` / `proxy` | 参照手法をどこまで保持したかを記録する実装区分 | このリポジトリ内の管理用語。先に具体的な処理と省略点を説明する。 |

## 参照手法の実装区分

以下はこのリポジトリ内の管理用ラベルです。参照手法の入力、予測対象、出力、損失、推論方法、処理単位を先に記述し、保持した処理と省略した処理から判定します。

| ラベル | 判定条件 | 記録する内容 |
| --- | --- | --- |
| `faithful` | 検証する主張に必要な参照手法の中核を保持する。 | 実行環境やデータ形式の差と、それが主張に影響しない根拠。 |
| `staged-faithful` | 中核を保持しながら、データ範囲や実行段階を限定する。 | 未検証の主張と次段階の条件。例えば同じ時系列モデル・損失を一部のgroupで検証し、全体評価を後段に残す。 |
| `proxy` | 主張に必要な中核を別の処理に置換または省略する。 | 検証できなくなる主張と代替した理由。例えば学習による候補選択を固定ルールへ置き換える。データ範囲が小さいことだけでは該当しない。 |

## 変更内容の分類

以下もこのリポジトリ内の管理用ラベルです。候補や実験の具体的な差分を説明するために使い、手法の一般名称として扱いません。複数の変更がある場合は、各処理について説明します。

| ラベル | 判定条件 | 例 |
| --- | --- | --- |
| `parameter` | 入力・予測対象・処理を変えず、既存の数値設定だけを変える。 | 学習率や既存の閾値の変更。 |
| `add-only` | 予測対象・出力・推論方法を保持し、特徴や補助項を追加する。 | 表形式データの分類器へ集約特徴量を追加する。 |
| `selector-only` | 固定された予測や候補のうち、選択するものだけを変える。 | 保存済み候補の順位付けや選択規則を変更する。 |
| `postprocess` | 予測後に結果を補正する処理を追加または変更する。 | 予測確率の校正や時系列予測の平滑化を追加する。 |
| `mechanism` | 予測対象・出力の単位を保持し、学習または推論の中核処理を変える。 | 同じ行単位の予測を、独立した推定からgroup内の同時推定へ変更する。 |
| `representation` | 入力、予測対象、出力、または参照する文脈の単位を変える。 | 時点ごとの分類からイベント区間の予測へ変更する。 |

既存の後処理の閾値だけを変える場合は`parameter`です。後処理として新たな学習や同時推定を導入する場合は、ラベルだけで説明を済ませず、入力・予測対象・出力・損失・推論方法のどこが変わるかを記録します。
